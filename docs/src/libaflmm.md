# The LibAFL-- Fuzzing Library

*by Andrea Fioraldi and Dominik Maier*

Welcome to `LibAFL--`, the Advanced Fuzzing Library.
This book shall be a gentle introduction to the library.

This version of the LibAFLmm book is coupled with the release 1.0 beta of the library.

This document is still work-in-progress and incomplete. The structure and the concepts explained here are subject to change in future revisions, as the structure of LibAFLmm itself will evolve.

Build it using `mdbook build` in this folder, or run `mdbook serve` to view the book.
