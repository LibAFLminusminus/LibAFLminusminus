# The LibAFL-- Fuzzing Library

*by Romain Malmain and Dongjia Zhang*

Welcome to `LibAFL--`, yet another Advanced Fuzzing Library.
This book shall be a gentle introduction to `LibAFL--`.

This document is still work-in-progress and incomplete.
The structure and the concepts explained here are subject to change in future revisions, as the structure of LibAFLmm itself will evolve.

Build it using `mdbook build` in this folder, or run `mdbook serve` to view the book.
