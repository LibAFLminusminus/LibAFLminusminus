# Components
In this chapter, we'll visit most of the `LibAFL--` components that you can use as the building block for your fuzzer.
The most important modules are [Executor](./components/executor.md), [State](./components/state.md), [Observer](./components/observer.md), [Feedback](./components/feedback.md), and [Stage](./component/stage.md).
If you want a quick start, then just make a pass on these modules.
