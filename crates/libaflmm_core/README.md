# `liabflmm_core`: Minimal set of core functions shared between `LibAFLmm` crates

The `libaflmm_core` crate has a range of useful functions shared across the [`LibAFL`](https://github.com/AFLplusplus/LibAFL) codebase.

## The `LibAFLmm` Project

This crate is part of the [LibAFLmm project](https://github.com/LibAFLminusminus/LibAFLminusminus).

The [README](../../README.md) contains the list of maintainers and licensing information.
