# `libaflmm_frida`: Binary-Only `Frida` Instrumentation for `LibAFLmm`

 <img align="right" src="https://raw.githubusercontent.com/AFLplusplus/Website/main/static/libafl_logo.svg" alt="LibAFL logo" width="250" heigh="250">

The `libafl_frida` crate offers binary-only instrumentation for `LibAFL` using the Frida dynamic instrumentation toolkit. It allows fuzzing closed-source binaries and applications on various platforms, including Android and iOS.

## The `LibAFLmm` Project

This crate is part of the [LibAFLmm project](https://github.com/LibAFLminusminus/LibAFLminusminus).

The [README](../../README.md) contains the list of maintainers and licensing information.
