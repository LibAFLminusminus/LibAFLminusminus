# `LibAFLmm`

`LibAFLmm` is the main library and contains the fuzzing components and their implementations.
A large part of this library depends only on Rust core+alloc and, thus, can run without any standard library.

## The `LibAFLmm` Project

This crate is part of the [LibAFLmm project](https://github.com/LibAFLminusminus/LibAFLminusminus).

The [README](../../README.md) contains the list of maintainers and licensing information.
